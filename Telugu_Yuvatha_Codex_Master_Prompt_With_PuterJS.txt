
TELUGU YUVATHA — MASTER CODEX PROMPT (WITH PUTER.JS GUIDANCE)

IMPORTANT NOTE:
If by "poter js" you mean "Puter.js" (https://puter.com), it is NOT recommended as the core framework
for this ecommerce platform. Puter.js is useful for browser-side utilities, but a production ecommerce
site should use:
- Frontend: Next.js 15
- Backend: Node.js + Express.js
- Database: MongoDB Atlas
- Payments: Razorpay
- Image Storage: Cloudinary
- Admin Dashboard: Separate Next.js app or route group

You MAY optionally use Puter.js for:
- quick file uploads
- AI-assisted product descriptions
- client-side utilities
But NOT as the main ecommerce backend.

LOADING EXPERIENCE
===============================================================================

1. On first visit, display full-screen loader.
2. Use SplitText/GSAP animation for:
   "WELCOME TO TELUGU YUVATHA"
3. Show custom logo text image (loader_text.png).
4. Background music begins automatically if browser allows.
5. After text animation, play hero intro video (36 seconds).
6. User can skip intro.
7. After video ends, smoothly transition into homepage.
8. Save a flag in localStorage so the intro only plays once per session.
